# ast4 Implementation Plan

**Goal:** tool version `ast4`: the kink-merge route keeps the smallest passing candidate at the first line count
that passes, over 4 snap variants.

**Spec:** `docs/design/2026-10-30-ast4-design.md`

## Tasks

1. **Route policy** (`nndc/heuristics/kinks.py`, `tests/test_kinks.py`)
   - `snap_fit(fit, spec, tol, U, y, window="line", round_const=True)`; `window="span"` is `tol · max span`.
   - `kink_merge(spec, mlp, version="ast3")`: `ast3` keeps first-pass order with the defaults. `ast4` checks all
     candidates per m and returns the smallest passing one (tie order in the design).
   - Tests:
     - `test_snap_fit_span_window`: the span window rounds to the old window's value;
     - `test_snap_fit_raw_const`: with `round_const=False`, the constant is the midrange at `tol > 0`;
     - `test_ast4_picks_smallest_at_first_m`: with a patched check, the smaller of two passing candidates wins,
       even when the larger comes first in `ast3`'s order;
     - `test_ast3_order_unchanged`: `ast3` still returns the first pass.
2. **Version wiring** (`ast_tool.py`, `run.py`, `cli.py`, `tests/test_run.py`)
   - `TOOL_VERSIONS` gains `ast4`, `OWN_CEX` gains `ast4`, `--name ast4`.
   - `refactor` passes the version to `kink_merge`, and the tanh rewrite applies to `ast4` too.
   - Test: `run_ast(rd, "ast4")` writes `ast4.py` and leaves `ast3.py` alone.
3. **Report** (`report.py`, `tests/test_report.py`)
   - Newest version `ast4 > ast3 > ast2 > ast`.
   - `ast_compare_rows(root, old, new)`; `kink_md` shows one table per older version present.
4. **Spike into the repo:** `experiments/spikes/ast4_snap_variants/` (script and README; the grids stay out).
5. **Development runs:** `ast4` on every sigmoid and tanh run. Check that `ast3` regenerates byte-identically on
   a scratch copy of 3 runs. Equivalence script: 0 differences. Data commit. Then the freeze commit.
6. **Held-out:** build sigmoid seeds 9–11 and tanh seed 3 (5 tasks), plus `formula.py`. Run frozen `ast4`, then
   `ast3`. `heldout.json` → `ast4`, the old one → `heldout_ast3.json`. Data commit.
7. **Reports and conclusions:** regenerate both roots' reports, `CONCLUSIONS.md`, `CLAUDE.md`. One final review.
